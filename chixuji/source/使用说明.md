# 迟叙机 · 使用说明（第 2 阶段）

这一版可以：注册登录、创建多个角色、写角色设定（带版本）、和角色聊天（DeepSeek 真实回复）、发图片给角色看、从任意一条消息分出新世界线、重新生成回复、纠正“崩人设”的回复、查看和管理角色的记忆、生成邀请码、查看模型花费。

角色回复用 DeepSeek V4 Pro；看图和整理记忆用 DeepSeek Flash。需要先在 `.env` 文件里填好 DeepSeek 密钥（见第 2 步之后的说明）。

---

## 1. 安装 Node.js（只需要做一次）

1. 打开 Node.js 官网 <https://nodejs.org/zh-cn>，下载 **LTS（长期支持版）**，版本号 24 或更新都可以。
   - 官网下载很慢的话，可以用国内镜像 <https://npmmirror.com/mirrors/node/>：点进最新的 `v24.x.x` 文件夹，Windows 下载以 `-x64.msi` 结尾的文件，Mac 下载以 `.pkg` 结尾的文件。
2. 双击安装包，一路点“下一步”即可。

不需要装 Docker、数据库或其他软件。

## 2. 启动

1. 把压缩包解压到一个固定的位置，例如 `D:\迟叙机`。
2. 启动：
   - **Windows**：双击 `启动.bat`。
   - **Mac**：右键点 `启动.command`，选“打开”（第一次需要这样做，以后直接双击即可）。
3. 第一次启动会让你输入**管理员邮箱**。输入你自己的邮箱，然后按回车。
4. 稍等两秒，浏览器会自动打开 <http://localhost:8080>。

黑色窗口要一直开着，**关掉窗口就是停止运行**。

### 填写 DeepSeek 密钥

用记事本打开文件夹里的 `.env` 文件（看不到的话，在文件夹“查看”里勾选“隐藏的项目”），找到这两行，把密钥填在等号后面，保存，然后关掉黑色窗口、重新双击启动：

```
DEEPSEEK_API_KEY=第一个密钥（角色回复和看图）
DEEPSEEK_MEMORY_API_KEY=第二个密钥（整理记忆，可不填）
```

不想花钱、只想试界面的话，把 `MODEL_PROVIDER=deepseek` 改成 `MODEL_PROVIDER=mock`，角色会用“测试回复”。

> Windows 第一次运行时，可能会弹出“防火墙”提示，勾选“专用网络”，然后点“允许”。这样同一个 WiFi 下的手机才能打开。

## 3. 第一次登录

1. 输入刚才填的管理员邮箱，点“获取验证码”。
2. 现在是测试模式，验证码会**直接显示在页面上**，不会真的发邮件。
3. 勾选“已年满 18 周岁”和“同意协议”，点“注册并进入”。

## 4. 用手机试

黑色窗口里有一行“同一WiFi的手机打开：http://192.168.x.x:8080”。手机连同一个 WiFi，在浏览器里输入这个地址就能打开。

## 纯前端版（试用）

双击「启动纯前端版.bat」，浏览器会打开 http://localhost:8081 。这是准备对外发布的版本：
- 不用登录，第一次打开确认年满 18 岁即可；
- 在「设置」里填自己的 DeepSeek 密钥（接口地址默认就是 DeepSeek 官方）；
- 所有内容只存在这个浏览器里，和服务器版（8080）的数据互不相通；
- 「设置」里可以导出 / 恢复备份。

### 卡密（联网激活）

纯前端版第一次打开要输入卡密。卡密由**服务器版**发放和验证。现在一个黑色窗口会同时开着两个版本（服务器版 8080 和纯前端版 8081）：双击「启动.bat」打开服务器版页面，双击「启动纯前端版.bat」打开纯前端版页面，二选一即可，不要两个都双击。

1. 服务器版 → 「管理」→「卡密」→ 生成；
2. 纯前端版打开后输入其中一个卡密 → 激活；
3. 每个卡密默认最多激活 2 台设备（清理浏览器数据也算换设备），满了在「卡密」页点「重置设备」；
4. 点「停用」后，对方最迟 3 天内联网检查时就会被要求重新激活。

**最重要的一个文件：`data\license-private.pem`（卡密私钥）。** 它决定了谁能签发有效的激活。不要发给任何人，不要传网盘；请另外拷一份到 U 盘保存。丢了它，已经卖出去的卡密就无法续期了。

现在激活服务器地址写的是 `http://localhost:8080`，只能在你这台电脑上测试。正式对外卖之前，要先把服务器版通过 Cloudflare Tunnel 放到你的域名上，我再把地址改成那个域名、重新打包。

### 朋友圈和日记（纯前端版）

- 桌面「圈」：仿微信朋友圈。你可以发文字和图片，TA 会看、点赞、评论；你心情不好时 TA 可能来私聊你。
- 桌面「记」：TA 每次聊完天写下的心里话。
- 这三件事默认**关闭**（每次都会花你的 API 额度），在「设置」→「TA 的自主行为」里打开。
- 朋友圈删除：自己的动态点时间旁的「删除」，会问你要不要让 TA 也忘掉；点自己的评论也能删。TA 的动态在「··」里点「隐藏」，TA 的评论点一下也能隐藏（只是你看不到）。

### 消息提醒（纯前端版）

- TA 主动私聊、评论、点赞、发圈、写日记、给照片钉纸条时：迟叙机里在顶部弹横幅；切到别的软件时弹系统通知（第一次会问你允不允许）；网页标签显示未读数。
- 迟叙机完全关掉时收不到；下次打开会汇总告诉你「你不在的时候」发生了什么。
- 「设置」→「消息提醒」：总开关、系统通知、提示音、每类事件单独开关、免打扰时段（默认关闭）。
- 桌面上「聊」「圈」「记」「房」都有红点。

### 房间（纯前端版，桌面「房」）

- 右边墙是照片墙（9 格）：点空相框挂照片、写一句话、选相框；TA 会看照片，在旁边钉一张小纸条，点纸条可以打开细读。点照片可以换位置或取下（取下时问要不要让 TA 也忘掉）。
- 架子上是记忆摆件：确认过的重要记忆会自动摆上去；也可以点右上角「摆件」或在「记忆」里点「做成摆件」，自己选样子和位置。点摆件能看到那段聊天。
- TA 会按时间做不同的事：深夜睡觉、早上在窗边、白天在书桌前、下午看书、刚聊完捧着手机等你；白天黑夜光线也会变。
- 点书桌上的日记本看日记，点床头的手机或 TA 本人去聊天。

## 6. 你的数据在哪里

- 所有数据都在 `data` 文件夹里，`xiaoshouji.db` 就是整个数据库。
- 每天自动备份到 `data\backups`，保留最近 7 天。
- **不要删除 `data` 文件夹**。以后更新程序时，只替换其他文件，`data` 保持不动。

## 7. 现在还不能对外开放

测试模式下，验证码会直接显示在页面上，所以程序**只允许本机和同一 WiFi 下的设备**获取验证码。从外网来的请求会被直接拒绝。第 3 阶段接入发邮件，并配好 Cloudflare Tunnel 之后，才会对外开放给朋友使用。

## 常见问题

**双击后窗口一闪就没了 / 提示没有找到 Node.js**
Node.js 没装好。重新安装第 1 步的安装包，装完后**重启电脑**再试。

**提示“需要 Node.js 22.13 或更新版本”**
你电脑上的 Node.js 版本太旧，按第 1 步重新安装最新的 LTS 版本。

**浏览器打不开 / 提示端口被占用**
可能已经开着一个迟叙机窗口了，先把它关掉。或者用记事本打开 `.env`，把 `PORT=8080` 改成 `PORT=8081`，再用 <http://localhost:8081> 打开。

**想改管理员邮箱**
用记事本打开 `.env` 文件（如果看不到这个文件，在文件夹设置里打开“显示隐藏的文件”），修改 `ADMIN_EMAIL=` 后面的邮箱，保存后重新启动。

### 壁纸和桌面小组件（纯前端版）

- 壁纸：「设置」→「壁纸」，选一张自己喜欢的图片；可以恢复默认。
- 唱片机：点唱片转起来 / 停下；点下面的歌名可以换封面图片、歌名、歌手（只是装饰，不放声音）。
- 天气：点天气小组件，用「我现在的位置」或搜索城市。每小时自动更新。
  - 网页读不到手机自带天气 App 的数据，所以是按位置从公开天气服务（Open-Meteo）查的。
  - 打开「让 TA 知道今天的天气」后，TA 聊天时会知道你那边的天气，每天的天气也会记进记忆（只保留最近几天）。
