# 待做方案（2026-10-29 定稿）：聊天背景、TA 查手机、TA 的心声、自定义图标

适用：纯前端版 + 安卓 App（服务器版暂不做）

## 1. 聊天背景
- 聊天页右上角「背景」：从相册选图；可调「变暗程度」「模糊程度」；可恢复默认
- 按人物保存（和 A 一张、和 B 一张），不按世界线区分
- 图片只存在本机，不花 API 额度

## 2. TA 查你的手机
共同规则：
- 两种开始方式：用户主动给；TA 按性格偶尔开口要（聊天里弹「给 TA 看 / 不给」，拒绝也是剧情）
- 每次都必须用户点同意；只看不改
- 设置里有总开关，关掉就完全不会发生
- 看完：聊天里出现「查手机记录」卡片 + TA 按人设反应 + 进 TA 的记忆（可能写进日记）
- 花费：每次约等于写一篇日记

2a. 查位置
- 同意后才定位，不后台定位、不持续跟踪
- 默认精确到区 + 街道（如「天河区·珠江新城附近 · 22:10」），可在设置改成只给城市
- 只把这句文字发给模型，不发门牌和经纬度
- 开关「位置记进记忆」：打开后 TA 会记住常去的地方
- 更精确（商场/楼栋）需高德开发者账号，以后再说

2b. 查你和其他人物的聊天
- 只限「同一个世界」里的其他人物；不同世界的人物 TA 不知道存在
- 每次弹列表，用户勾选给看哪几个人的聊天
- 只看对方当前世界线最近约 30 条聊天；对方的人设、记忆、日记看不到
- 被翻的人物不知道这件事（只进查看者的记忆）

不做：读取真实微信（系统层面读不到）

## 3. TA 的心声（看思考过程，方案 B）
- 每条回复顺带生成一句 TA 口吻的心里话
- 气泡下「TA 当时在想…」，点开才显示
- 不进聊天历史、不进记忆，只给用户看
- 设置里总开关，默认关闭；每条回复多花一点点额度

## 4. 自定义图标（全部由玩家上传，不做预设）
- 小手机内 10 个功能图标：长按 → 换图（自动圆角）/ 改名字 / 恢复默认
- 手机桌面图标（仅安卓 App）：「设置」→「创建桌面图标」，选图 + 起名（可伪装成「备忘录」等），生成桌面快捷方式
  - 限制：部分手机会在新图标上加小角标；原「小手机」图标仍在（可收进文件夹）；网页版做不了
