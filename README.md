# 我的項目合集

和 Claude 一起做的三個項目。

| 資料夾 | 項目 | 說明 |
|---|---|---|
| [`chixuji/`](chixuji/) | **迟叙机** | 人機戀「小手機」AI 陪伴應用。多角色、共享世界觀、世界線分支、房間照片牆、像素小人。網頁版（PWA）+ Android APK，模型用 DeepSeek。 |
| [`novel-writing/`](novel-writing/) | **世界線寫作台** | AI 寫小說工具的可試玩原型。卡密登入、按字數扣餘額、人物檔案與設定自動帶入、世界線分支、局部改寫、導出 TXT / Word。 |
| [`badminton-booking/`](badminton-booking/) | **飛翔羽毛球館訂場** | 10 片場地的微信小程序訂場系統的可試玩原型（客戶端 + 管理後台）：按小時訂場、平/假日定價、活動商品與核銷碼、報表。 |

## 怎麼打開

- **世界線寫作台**、**羽毛球館訂場**：都是單一網頁檔，下載 `index.html` 用瀏覽器打開就能看。（寫作台的「生成正文」需要在 Claude 裡打開才能用。）
- **迟叙机**：見 [`chixuji/source/使用说明.md`](chixuji/source/使用说明.md)。DeepSeek 密鑰要自己填進 `.env`，倉庫裡沒有附。

## 注意

- 這裡的示例數據（人名、電話、卡密）都是假的。
- 倉庫裡**沒有**任何真實的 API 密鑰、APK 簽名檔或密碼；要自己打包 APK 需要用自己的簽名檔。
- 羽毛球館的正式上線版源碼（微信雲開發）不在這個倉庫。
